Subdomain Takeover PoC — docs.developers.intility.com

This page demonstrates that the hostname docs.developers.intility.com can be served by a GitHub Pages site outside the Intility organization, due to a dangling CNAME record combined with absent organization-level domain verification.

Vulnerable component
CNAME docs.developers.intility.com → intility.github.io with no claiming repository in the Intility GitHub organization, and no covering verified domain at the org level.
Recommended remediation
(1) Verify intility.com at the GitHub organization level (Settings → Verified and approved domains). This protects all current and future *.intility.com subdomains.
(2) Remove or repoint the dangling CNAME record.
(3) Audit all DNS records pointing to third-party hosting providers (github.io, herokuapp.com, azurewebsites.net, s3.amazonaws.com, etc.) for similar dangling references.
